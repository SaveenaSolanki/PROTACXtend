Supported Slash Commands

Trigger specialized multi-agent subroutines directly.

/design
Target-to-lead multi-agent PROTAC assembly, linker optimization, and Pareto ranking.
/predict
Chemprop ensemble + TACK model prediction for $DC_{50}$ and $D_{\max}$ metrics.
/dock
P4ward 3D ternary complex simulation and SE(3) geometric feasibility scoring.
/admet
hERG, AMES, BBB, TPSA, Lipinski, and Veber safety and drug-likeness risk profiling.
/audit
Feynman-style decision trace audit verifying claims against empirical tool outputs.
/replicate
Benchmark dataset replication and model validation runs with full provenance logs.

Getting Started with PROTACXtend

PROTACXtend can be installed via PyPI, cloned from GitHub, or run locally via the command executable.

Installation Commands

# Clone official repository
git clone https://github.com/the-ahuja-lab/PROTACXtend.git
cd PROTACXtend

# Create virtual environment & install requirements
conda create -n protacxtend python=3.10 -y
conda activate protacxtend
pip install -r requirements.txt
pip install -e .

System Diagnostic Check

protacxtend status

Architecture & 23-Node Feynman Stack

PROTACXtend organizes PROTAC design into 23 auditable agent nodes running on top of a 73-method chemistry engine (protac_toolbox.py).

Key System Components

1. Supervisor & Planning Node: Natural language prompt parsing and multi-turn policy execution.

2. Target & Warhead Resolver: Automated retrieval from ChEMBL, PubChem, UniProt, and BindingDB.

3. Generative Linker Assembly: Rule-based, curated, and GRU generative linker attachment scanning.

4. Physics + ML Scoring: Chemprop deep learning ensemble for $DC_{50}$ / $D_{\max}$ and P4ward 3D ternary complex docking.

Workflows & Slash Commands

Execute design, prediction, and docking workflows from the CLI or Python API.

# End-to-end design run
protacxtend design --target "BRD4" --e3 "CRBN" --num-candidates 16

# Predict degradation metrics
protacxtend predict --smiles "CC1=C..." --target "BRD4"

# Launch local workbench
protacxtend serve

API & REST Endpoints Reference

PROTACXtend exposes a Python API in package synglue_agent and REST endpoints via FastAPI.

Python API Example

from synglue_agent.agents.graph import run_syn_glue_workflow

state = run_syn_glue_workflow("Design 10 PROTACs for HMGB2 with CRBN")
print(state["final_candidates"])
